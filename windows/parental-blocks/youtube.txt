# SafeHouse — YouTube parental block source list
#
# Canonical hostname list for the "YouTube" parental block toggle.
# This is the SOURCE OF TRUTH for `safehouse_setup toggle youtube --block`,
# which appends a `0.0.0.0 <host>` line for each entry below to the live Windows
# hosts file (and `-Allow` removes that section again).
#
# STANDING POLICY since 2026-08-26: YouTube is ALLOWED, at all times, on the parent's
# call. The 2026-08-19 block was lifted in every lane -- the resolver rules are gone from
# adguard/user-rules.txt, the Pi-hole regexes are commented out in
# blocklists/parental-denylist.txt, and the panel's schedule is set to "allowed".
# This file is NOT a block: it is only the hostname list `safehouse_setup toggle youtube
# --block` would use IF a parent chose to block the Windows box again, and the script
# never applies it on its own. It is kept so that choice stays one command away.
#
# Format: one hostname per line. Blank lines and lines starting with '#' are ignored.
# To block more YouTube surfaces, add hostnames here, then re-run the toggle.

youtube.com
www.youtube.com
m.youtube.com
youtu.be
music.youtube.com
youtube-nocookie.com
www.youtube-nocookie.com

# YouTube Kids - a separate surface that the main youtube.com block does NOT cover.

# InnerTube / API endpoints. The YouTube PWA and the mobile-style clients talk to
