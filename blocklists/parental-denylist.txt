# Parental content layer (DNS) — Pi-hole regex, one per line.
#
# This file is the PARENTAL CONTENT layer, loaded into Pi-hole's domainlist as
# type 3 (regex deny) with comment 'SafeHouse-Parental' (kept distinct from the
# ad-network regex in regex-denylist.txt, comment 'SafeHouse').
#
# PUBLIC-REPO SAFE: this file lists ordinary product/service domains by NAME only.
# Adult / NSFW content is deliberately NOT listed here — those domains are covered
# network-wide by referencing an external NSFW blocklist URL in adlists.txt (a link,
# never the domains themselves). Keep it that way: do not paste adult domains here.
#
# One regex per line catches a whole domain family incl. all subdomains. Lines
# starting with '#' are ignored. Apply with ../scripts/load-blocklists.sh.

# --- YouTube family (BLOCKED — standing policy since 2026-08-19) ---
# YouTube is not allowed on this network. It is blocked here at the Pi-hole layer and,
# more importantly, in adguard/user-rules.txt: AdGuard Home is the resolver actually on
# :53, with Pi-hole behind it on :5353, so these lines exist to keep the two lanes
# saying the same thing rather than to be the enforcement on their own.
# This takes YouTube Music with it — music.youtube.com is the same domain family.
# To allow YouTube again, comment these out and run ../scripts/load-blocklists.sh, and
# remove the matching rules from AdGuard's user rules.
(^|\.)youtube\.com$
(^|\.)youtu\.be$
(^|\.)youtubekids\.com$
(^|\.)youtube-nocookie\.com$
(^|\.)googlevideo\.com$
(^|\.)ytimg\.com$
# InnerTube/API endpoints, named one by one. The bare googleapis.com would take the Play
# Store, Drive and Maps with it — far more than YouTube.
(^|\.)youtubei\.googleapis\.com$
(^|\.)youtube\.googleapis\.com$
